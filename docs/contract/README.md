# 契约目录

本目录是数据与接口契约的唯一基线。

- **当前基线**：`data-format.v2.md`（清洗）、`db.v2.sql`（存储）、`api.v2.md`（查询）。

canonical 是数据库：清洗后的数据逐格入库，`db.v2.sql` 是规范形态。

| 文件 | 作用 |
|---|---|
| `data-format.v2.md` | 上游 HTML → 清洗后的事实的契约：分层、字段语义、不变量、失败条件 |
| `db.v2.sql` | 存储结构：逐格观测、字典/轴/日历/房间/配置/发布 |
| `api.v2.md` | 查询契约：3 端点、参数、四段式响应、错误码、新鲜度 |
| `../config/env.example` | 部署级环境变量（数据库连接等）；业务设置走 WebUI，写入数据库配置 |

## 设计决定记录

| 决定 | 理由 | 日期 |
|---|---|---|
| 观测按 **12 小节**落盘，不按上游原生的 5 大节 | 12 小节是 5 大节的超集：上游将来若给出块内不一致的粒度，契约不必改；消费方不必到处做展开。代价（体积、块归属）用"稠密矩阵编码 + 轴显式化 + 解析期断言块内一致"压掉 | 2026-10-03 |
| 状态用**语义键**（`free` / `class` / …）而不是整数 ID | 数据自描述；字典改版不静默污染旧数据（`dict_version` 随发布记录） | 2026-10-03 |
| 清洗**无损**：保留 `name_raw`，未知与复合保留原文本 | 上游只返回当前周与未来数周，历史周重采不可得；清洗只该加派生字段，不该删源字段 | 2026-10-03 |
| 未知符号**降级**为 `unknown` 状态并计数，不再让整轮不发布 | 区分"不认识一个新符号"与"管线坏了"；底线"不把未知当空闲"不变 | 2026-10-03 |
| 全量入库、**无白名单**，查询直接扫全库 | 需求变更：不按楼分组、不设白名单，空字符串请求上游、存所有房间，用户全库查询。采集范围已被 2026-10-09 行取代，本行不再表示拉全校 | 2026-10-03 |
| 采集按管理员配置的**教学楼白名单**逐楼请求 `jxlbh`，不拉空参数再过滤 | 白名单单位是教学楼编号，不是房名关键词，也不是教室类型。选中的楼带上行政归属该楼但房名不含楼名的教室。房间记下所属楼。多次请求拖慢同步，可接受。查询只扫已入库房间。见 `../decisions/2026-10-09-keep-teacher-status-api.md` | 2026-10-09 |
| **不设分组**（取代当天较早的多对多方案） | 分组这一层从数据流整体拿掉；查询只剩关键词 + 周/星期/节次 | 2026-10-03 |
| 存储用**全关系表逐格一行**（`observation`），数据库是唯一 canonical | 体积约 700 万行对 PostgreSQL 无压力；逐格最可读、区间查询一条 SQL | 2026-10-03 |
| 查询 API 重定为 **3 端点 + 四段式响应** `{code, message, data, request_id}` | 端点合并、错误码分层、`request_id` 可追踪 | 2026-10-03 |
| 发布保留 **current + previous** 两版，WebUI 发布后对比 + 一键回退 | 可回退一次；版本对比复用两版差集，无需额外存储 | 2026-10-03 |
| 业务设置走 **WebUI 管理面板**（教务账号 / 飞书 webhook 与签名 / OCR 地址 / cron），不再走环境变量 | 管理员在面板维护，写入数据库配置；部署级变量（如 `DATABASE_URL`）仍走 env | 2026-10-03 |
| 采集时间由 WebUI 配置的 **cron 表达式**驱动 | 不再用 systemd timer 固定 04:10。任务内容见 2026-10-09 同步行，不再按普通日期只采近 4 周 | 2026-10-03 |
| 定时与手动都做**全量同步**：各周矩阵 + 聚合矩阵上的占用格明细一次 | 明细按周下钻请求更多或相近，却只覆盖近几周。各周矩阵请求量相对明细可忽略，用来判定某周是否空闲。断点续传，每秒至多 2 次，不用 15 分钟掐断。不存申请人与任课教师。见 `../decisions/2026-10-09-saturday-full-sync.md` | 2026-10-09 |
| 教学周历由一次日期采样生成，查询用 `date_offset` 查本地 `term_week` | 采集器请求 `main_index_loadkb.jsp` 只取「第 X 周 / 共 Y 周」，反推第 1 周周一后写入全部周一。查询不调用该接口，也不用当天周次重算。见 `../decisions/2026-10-09-term-week-from-one-sample.md` | 2026-10-09 |
| 查询按**小节区间**，不必对齐上游大节 | 采集时把大节拆成小节。前端传有序的起止小节，区间可跨块。不接收跳节列表。见 `../decisions/2026-10-09-query-by-node-range.md` | 2026-10-09 |
| 查询与采集由**同一个常驻进程**启动 | 一个入口同时听 HTTP 并跑 cron。采集仍是独立包，公开路由不登录教务。`cmd/migrate` 仍单独跑一次。见 `../decisions/2026-10-09-single-process-entry.md` | 2026-10-09 |
| 验证码识别走 **ddddocr-fastapi** 的 `POST /ocr` | 生产环境已 Docker 部署；图片 base64 上传，识别文本在响应 `data`，以 `code=200` 判成功 | 2026-10-03 |
