# 契约目录

本目录是数据与接口契约的唯一基线。

- **v2 是当前基线**：`data-format.v2.md`（清洗）、`db.v2.sql`（canonical 表结构）、`api.v2.md`（查询）。
- **`reference-v1/` 是考古参考**，不是基线：它是旧设计（按 12 小节展开的 JSON 周文件 + 4 个 GET 的旧载荷）留下的文件，只在需要对照或追问"当初为什么那样"时读。

canonical 是数据库：清洗后的数据直接入库，`db.v2.sql` 是规范形态。JSON 只是导出/调试格式，不参与发布判定。

| 文件 | 作用 |
|---|---|
| `data-format.v2.md` | 上游 HTML → 清洗后的事实的契约：分层、字段语义、不变量、失败条件 |
| `db.v2.sql` | canonical 表结构（发布物、观测、字典、轴、日历、质量与校验） |
| `api.v2.md` | 查询契约：路径、参数、载荷、错误码、新鲜度与缓存 |
| `../config/rooms.json` | 白名单与分组视图定义，人工维护 |
| `reference-v1/` | 旧契约，只作考古 |

## 设计决定记录

| 决定 | 理由 | 日期 |
|---|---|---|
| 观测按 **12 小节**落盘，不按上游原生的 5 大节 | 12 小节是 5 大节的超集：上游将来若给出块内不一致的粒度，契约不必改；消费方不必到处做展开。代价（体积、块归属）用"稠密矩阵编码 + 轴显式化 + 解析期断言块内一致"压掉 | 2026-10-03 |
| 状态用**语义键**（`free` / `class` / …）而不是整数 ID | 数据自描述；字典改版不静默污染旧数据（`dict_version` 随发布记录） | 2026-10-03 |
| 清洗**无损**：保留 `name_raw`、`capacity`，未知与复合保留原文本 | 上游只返回当前周与未来数周，历史周重采不可得；清洗只该加派生字段，不该删源字段 | 2026-10-03 |
| 未知符号**降级**为 `unknown` 状态并计数，不再让整轮不发布 | 区分"不认识一个新符号"与"管线坏了"；底线"不把未知当空闲"不变 | 2026-10-03 |
| 保留**全量房间**，白名单只作查询视图 | 发布物现在是本机私有库，不再是可能公开的仓库与 Vercel；房间名与占用状态不是敏感信息，课程、教师、申请人仍然不采 | 2026-10-03 |
| 分组**多对多**，零命中降为告警 | 分组是筛选视图，不是身份；重叠视图（"JA" 与"所有教学楼"并存）是正常需求 | 2026-10-03 |
| **数据库是唯一 canonical**，JSON 只作导出 | 消除"周文件与库表互为镜像"带来的两套规范漂移 | 2026-10-03 |
| 查询层**路径与载荷一并重定** | 载荷词汇（语义键、节点区间）与资源边界一起重新表述，不留旧词汇的翻译层 | 2026-10-03 |

改这里的任何一条，都要先改本表，再改对应的三个文件；`reference-v1/` 不动。
