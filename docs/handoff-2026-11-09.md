## 下一步：`collect-runner`

spec 目录：`specs/2026-11-09-collect-runner/`（本轮刚写，若不存在就先写）。

范围：从 `runner.Start` 被调用，到一轮 `collect_run` 落成 `success`/`partial`/`failed`，全都在这个 spec 里。三个必须收口的未决项：

1. **`collect_run.window_start` 没有写入口** —— 现在 `collect_run` 的 `window_start`/`window_end` 从来没被写过；窗口要从「当前时间 + 教务学期」算出并落库。
2. **明细任务的「不可用格」列表来源未定** —— `pipeline.TaskFetcher` 缺 `Cells`/`Details`，矩阵页给的是每格状态，明细页给的是单格详情；要定义「哪些格需要进明细任务」。
3. **续跑时内存候选重建** —— `pipeline.Run` 不暴露 `Accepted` 房间，断点续跑要能从库里（`collect_run_room`）重建候选。

另外要接的：白名单 `jxlbh` 到教务 building id 的映射、`term`/`weeks` 从 `upstream` 取、`publish.Build → Validate → Commit`。
