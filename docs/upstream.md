# 上游教务系统接口与解析契约（脱敏摘要）

> 只读事实记录，不含账号、Cookie、Token、验证码或原始完整页面。用于排查接口变化。来源：旧仓库
> `easy-qfnu-kjs-legacy` 的探测记录（Issue #29）与 `docs/get-classroom-staus.md`、`docs/get-week.md`。

## 1. 登录

- CAS 统一认证：登录页取 `salt`/`execution`，AES/CBC/PKCS7 加密密码，提交后带 ticket 跳转 SSO。
- 实现：`pkg/cas`（自旧仓库迁移）。验证码用本地离线识别：默认调用
  `scripts/ocr_ddddocr.py`（Python `ddddocr`），可用 `OCR_CMD` 指向任意本地命令；
  不做任何网络 OCR 服务。

## 2. 学期与当前周

| 用途 | 请求 | 说明 |
|---|---|---|
| 当前学期 | `GET /jsxsd/kbxx/jsjy_query` | 默认页 HTML 含 `YYYY-YYYY-N` 学期 |
| 当前周/总周数 | `GET /jsxsd/framework/jsMain_new.jsp?t1=1` | 教学周内显示“第 X 周/共 Y 周”；非教学周显示“不在教学周历内” |

两者只由本地采集器（已登录）读取，浏览器/Vercel 不直接访问。

## 3. 周状态查询

```
POST /jsxsd/kbxx/jsjy_query2
typewhere=jszq
xnxqh=<学期>
jsmc_mh=            （留空 = 全校）
zc / zc2 = 同一周次
xq=1, xq2=7         （星期一到星期日）
jc / jc2 不传        （全天）
jszt 不传            （全状态）
```

实测（2025-2026-3 学期第 2 周）：

- 全校 2079 行、约 9.41 MB、每行 35 状态格 = 7 天 × 5 大节、约 1 秒；
- 每行含稳定 `jsbh`（2079 个全部唯一）；
- 房名一律带容量 `(n/N)`。

## 4. 节次块（关键解析契约）

表头 `tdvalue` 覆盖 12 个小节，共 5 个大节；块内小节状态一致（业务不变量）：

```text
0102    → 01、02
030405  → 03、04、05
0607    → 06、07
0809    → 08、09
101112  → 10、11、12
```

- 若返回的块集合不再是这 5 个 → 作息表变化，采集必须阻断（等待人工确认），不得自动适配。
- 状态文本 → ID：`◆`1、`Ｊ`2、`Ｘ`3、`Κ`4、`空闲`5、`Ｇ`6、`Ｌ`7、`完全空闲`8、`M`9；空单元格 = 5（空闲）。出现未知文本 → 结构失败。
- 可用状态：5（空闲）、8（完全空闲）；范围查询要求所选起止小节全部可用。
- 全学期范围（zc=1..20）返回聚合矩阵，不能恢复逐周数据 → 必须按周请求，每周 1 次约 20 次/学期。

## 5. 名称规范化

- NFKC → 反复删除纯数字容量片段 `(n/N)` / `（n/N）` → 压缩清理空格；其他括号（方位/校区）保留。
- 例：`F126(90/0)` → `F126`；`篮球馆（东）(25/0)` → `篮球馆（东）`。
- 仍存在同名不同 `jsbh`（探测期 4 组精确同名）：`jsbh` 是唯一身份。

## 6. 变化排查指引

采集失败并标记未知错误码时，依次核对：

1. 登录页/非法访问特征（会话或账号权限）；
2. 学期页与周次页仍可解析；
3. `tdvalue` 块集合是否仍为 5 大节；
4. 状态文本是否出现新符号；
5. 房名是否出现新的括号/容量形态。
